# The Eclipse

横スクロール型 2D アクション RPG（DxLib / C++17 / Visual Studio 2022 / 1920x1080）。

「自由に動いて斬る」リアルタイムアクションと、モーションが固定される
**ソードスキル** を組み合わせたハイブリッド戦闘のプロトタイプです。

```
タイトル → ホーム（装備 / クエスト / 強化 / 設定）→ クエスト（2〜4 フロア＋ボス）→ リザルト → ホーム
```

---

## 1. ビルド方法

### 必要なもの

| 項目 | 内容 |
|------|------|
| IDE | Visual Studio 2022（C++ によるデスクトップ開発） |
| ライブラリ | [DxLib](https://dxlib.xsrv.jp/)（バージョン指定なし / VC 用パッケージ） |
| 言語 | C++17 |

### 手順

1. DxLib の VC 用パッケージを入手し、`プロジェクトに追加すべきファイル_VC用` フォルダを
   任意の場所に置きます（`DxLib.h` や `DxLib.lib` が入っているフォルダです）。
2. 下のどちらかで場所を指定します。
   - **環境変数**: `DXLIB_DIR` にそのフォルダのパスを設定する（推奨）
   - **配置**: リポジトリ直下に `external\DxLib\` として置く
3. `TheEclipse.sln` を Visual Studio 2022 で開く。
4. 構成を `Debug` または `Release`、プラットフォームを `x64`（または `x86`）にしてビルド。
5. `bin\<プラットフォーム>\<構成>\TheEclipse.exe` が生成され、`assets` が自動でコピーされます。

> パスの解決は `TheEclipse\DxLib.props` で行っています。別の配置にしたい場合はここを編集してください。
> リンクエラーが出る場合は、ライブラリディレクトリ（`$(DxLibLibDir)`）が正しいかを確認してください。
> DxLib は **静的 CRT（/MT・/MTd）** と **マルチバイト文字セット** を要求するため、
> プロジェクト側で既にその設定を行っています。
>
> `LNK2019` 等の未解決シンボルが出る場合は、DxLib.h の自動リンク（`#pragma comment`）が
> 効いていない可能性があります。プロジェクトのプロパティ →
> リンカー → 入力 → 追加の依存ファイル に、お使いの DxLib パッケージ同梱の
> `.lib` 一式（`DxLib.lib` など）を追加してください。

### 文字コードについて

ソースは **UTF-8（BOM なし）** で記述し、コンパイラオプション `/utf-8` と
`SetUseCharCodeFormat(DX_CHARCODEFORMAT_UTF8)` を対で使用しています。
日本語が文字化けする場合はこの 2 つが有効かを確認してください。

## 2. 操作方法

| 操作 | キー / マウス |
|------|--------------|
| 移動 | `A` / `D`、`←` / `→` |
| **奥・手前へ移動** | `W` / `S`、`↑` / `↓` |
| ジャンプ | `SPACE` |
| 通常攻撃（3 段コンボ） | 左クリック / `J` |
| ガード | 右クリック / `K`（長押し・被ダメージ約 72% カット） |
| **パリィ** | **ガード中に左クリック**（敵の攻撃に合わせる） |
| 回避ダッシュ | `SHIFT`（無敵時間あり） |
| ソードスキル | `1` `2` `3` `4` / 右下アイコンをクリック |
| メニュー（戦闘中） | `ESC`（ゲームに戻る / 装備 / 設定 / リタイア） |
| 決定 / キャンセル | `ENTER` / `ESC` |

ホームでは `1`〜`4` キーでも下部タブを開けます。UI はすべてマウスで操作できます。

## 3. 実装済みの内容

### 奥行き（ベルトスクロール）

`W` / `S` で画面の奥・手前へ移動できます。2D の横スクロールのまま、
Z 軸方向にも動ける『ファイナルファイト』型のフィールドです。

- 奥に行くほど**小さく・暗く**描画され、手前のキャラクターが前面に重なります。
- **奥行きが合っていないと攻撃は当たりません**（許容幅は約 58）。
  敵もプレイヤーの奥行きに合わせて回り込んできます。
- ボスの咆哮のように、奥行き全域を巻き込む攻撃もあります。
- 床は奥行きの帯として描画され、歩ける範囲がひと目で分かります。

### 戦闘

- **通常攻撃**: 3 段コンボ。段ごとに倍率・ノックバック・踏み込みが異なり、先行入力に対応。
- **ソードスキル**: 発動中はモーション固定。定義された時刻に多段ヒットが発生し、
  技によって無敵時間・突進・打ち上げが付く。**クールダウン制**（MP も消費）。
- **パリィ**: ガード中に攻撃ボタンを押すと 0.18 秒の受付が発生し、
  その間に正面から攻撃を受けると成立。ダメージ 0・MP 回復・無敵に加え、
  **相手をよろけさせて反撃の隙**を作る。飛び道具は威力 1.8 倍で**弾き返す**。
  失敗すると 0.5 秒間パリィできない硬直が発生（連打は不可）。
- 武器種ごとに専用スキル **6 種（計 30 種）**。**スキルツリーで解放し、4 つまで装備**できます。
  武器を変えるとロードアウトは自動で組み直されます。
- ヒットストップ、画面振動、クリティカル、コンボカウンタ、ガード、被弾無敵。

### 武器種（5 種）

片手剣 / 片手棍 / 短剣 / 細剣 / 槍。射程・攻撃速度・クリティカル傾向がそれぞれ異なり、
プレースホルダー描画の見た目（武器形状）も変わります。

### 装備・ドロップ

- スロット: **武器 / 頭 / 体 / 盾 / 腕 / 手 / 足**（7 種）
- レアリティ: **N / R / SR / SSR / UR**（倍率・強化上限・色が変化）
- 入手はガチャではなく **ボスドロップ＋道中ドロップ** のみ。
- ステータス: 攻撃力・防御力・最大 HP / MP・クリティカル率・クリティカル倍率・
  移動速度・攻撃速度・MP 回復。個体差（±6%）あり。
- **強化（+1 ごとに +9%）**: col と強化結晶を消費。+3 までは必ず成功、以降は成功率が低下
  （失敗しても強化値は下がりません）。売却も可能。
- **耐久力**: 武器は攻撃を当てるたび、防具は被弾するたびに消耗します。
  最大値はレアリティと強化値で決まり（N 100 → UR 180、強化 +1 ごとに +4）、
  **クエスト中でも 0 になった時点でその場で消滅**します（画面中央に警告を表示）。
  鍛冶屋で修理でき、傷んだ装備は売値も下がります。

### 鍛冶屋

ホームの「鍛冶屋」タブで、装備の**強化**と**耐久力の修理**を行います。

- 修理費用は減った耐久力 × レアリティ係数（N は 8 col/点、UR は 24 col/点）。
- 「すべて修理」で所持品をまとめて修理できます。
- 装備の耐久力が 25% 以下になるとホーム画面と鍛冶屋タブに警告が出ます。
- 耐久力はクエスト中にリアルタイムで減り、**0 になった装備はその場で失われます**。
  壊れた瞬間に警告が出るので、`ESC` →「装備」から替えの装備に持ち替えられます
  （壊れた分はリザルト画面でも一覧表示されます）。

### スキルツリー

- 各武器種に **2 系統 × 3 段** のツリー。系統は「火力特化」と「機動・範囲」。
- 下の段は上の段が前提。解放には **スキルポイント（SP）** を消費（1 → 2 → 3 SP）。
- SP は **レベルアップ 1 回につき 1**、クエスト初回クリアで **+2**。
- 各武器の起点スキルは最初から解放済み。初期 SP は 3。
- **装備できるのは 4 つまで**。ホームの「スキル」タブから装備します。
  未使用 SP があるとタブにバッジが出ます。

### クエスト

| # | クエスト | フロア数 | ボス |
|---|---------|---------|------|
| 1 | はじまりの森 | 3 | 深緑の狼王 ファングルフ |
| 2 | 石牢の回廊 | 4 | 石牢の守護者 ゴーレム・ガルド |
| 3 | 蝕の祭壇 | 4 | 蝕の騎士 エクリプス・ナイト |

- 各フロアの敵を全滅させるとゲートが開き、右端から次のフロアへ。最終フロアがボス戦。
- ボスは **HP 70% / 35% でフェーズ変化**（攻撃力・速度上昇、予備動作短縮）。
  薙ぎ払い・突進・叩きつけ＋衝撃波・遠距離弾・連続斬り・咆哮をパターン選択で使い分けます。
- 終了時に **リザルト**（ランク評価 / 戦闘記録 / 報酬 / ドロップ一覧）を表示してホームへ戻ります。

### UI

- 左上にキャラアイコン＋HP / MP バー、上部中央にボス HP、右下にスキルバー（クールダウン表示）。
- 戦闘中は画面上部の `MENU` から **設定** と **クエストリタイア**。
- ホーム下部に **装備 / スキル / クエスト / 鍛冶屋 / 設定** の 5 タブ（`1`〜`5` キーでも開閉）。
- 戦闘中の画面上にメニューボタンは置かず、`ESC` のみで開きます。
  メニューには**装備タブ**があり、壊れた装備をその場で交換できます
  （交換すると能力値と見た目が即座に反映されます。戦闘中の売却はできません）。
- 設定画面は 2 カラム構成（左: 音量・表示・開発者向け／右: 操作一覧）。
- 日本語フォント対応（`assets/fonts` に配置したフォントを自動読み込み）。

### セーブ / ロード

- `save/save.txt` に**平文**で保存します（内容を確認・編集しやすい形式）。
- **自動セーブ**: ホームに戻ったとき / 出撃前 / ゲーム終了時。
- 起動時にセーブデータがあれば自動で読み込みます。
- 設定画面の「セーブデータ削除」から消去できます（2 回押しで確定）。
- 保存内容: レベル・経験値・所持品（強化値・個体差・耐久力を含む）・装備・col・強化結晶・
  解放スキル・スキルポイント・スキル構成・クリア状況・各種設定。

### 装備スキン

装備がキャラクターの見た目に反映されます。

- **体装備**: 全体の配色とマントの有無
- **頭装備**: 兜なら頭部が角張り、面のスリットと前立てが付く
- **盾 / 武器**: 色と発光。蝕シリーズは常時発光します
- **レアリティ**: SR 以上はレアリティ色が差し色に混ざります
- 素材を用意する場合は各装備に `spriteFolder` を設定済みです（`assets/skins/<folder>`）

### マウスカーソル

- 起動時と画面モード切り替え時に `SetMouseDispFlag(TRUE)` を呼び、
  フルスクリーンでもカーソルが表示されるようにしています。
- それでも見えない環境向けに、設定の「カーソルを描画」で
  **ソフトウェアカーソル**（ゲーム側で矢印を描画）へ切り替えられます。
  ON のときは OS のカーソルを隠すので二重表示にはなりません。

### デバッグモード（開発者向け）

設定画面の一番下のトグルで有効化します。戦闘中に以下が使えます。

| キー | 機能 |
|------|------|
| `F1` | 無敵の切り替え |
| `F2` | フロアの敵を殲滅（ボス含む） |
| `F3` | HP / MP 全回復 |
| `F4` | 当たり判定の表示 |
| `F5` | col +10000 / 強化結晶 +50 / SP +5 |

有効時は左側に座標・奥行き・状態・判定数などの情報パネルを表示します。

### 素材

スプライトシートと PNG 連番の **両方** に対応。未配置の場合は図形ベースの
プレースホルダー（武器種・敵種別ごとに形状が変化）で動作します。
配置方法は [`assets/README.md`](assets/README.md) を参照してください。

## 4. ディレクトリ構成

```
The-Eclipse/
├── TheEclipse.sln
├── TheEclipse/
│   ├── TheEclipse.vcxproj / .filters
│   ├── DxLib.props              DxLib の場所を解決
│   └── src/
│       ├── main.cpp             エントリポイント（WinMain）
│       ├── Common/              ベクトル・矩形・色・数学・文字列
│       ├── Core/                DxLib 初期化 / 入力 / フォント / リソース / カメラ / シーン管理
│       ├── Graphics/            描画ユーティリティ / アニメーション / キャラ描画
│       ├── Game/                ステータス・装備・スキル・戦闘・敵・ボス・ステージ・クエスト
│       ├── UI/                  HUD・各種パネル・ウィジェット
│       └── Scenes/              Title / Home / Quest / Result
└── assets/                      画像・フォント（詳細は assets/README.md）
```

ヘッダ（`.h`）と実装（`.cpp`）は全て分離しています。

## 5. 主要な調整ポイント

| スキルポイントの入手量 | `src/Game/PlayerData.cpp` / `src/Scenes/QuestScene.cpp` |

| 強化コスト・成功率・修理費用 | `src/Game/Inventory.cpp` |

| 敵の性能 | `src/Game/EnemyDatabase.cpp` |
